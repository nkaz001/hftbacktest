# 改动总结 - 2026-01-06

## HFT Supervisor - 多Bot进程管理系统 (Phase 1)

### 新增 `supervisor` crate

实现了 HFT 多Bot管理系统的核心组件，用于管理多个交易策略进程的生命周期。

### 新增文件

**supervisor/Cargo.toml** - crate 配置
- 依赖: tokio, serde, toml, clap, nix, notify, tracing

**supervisor/src/config.rs** - 配置解析
- `ClusterConfig` 结构体解析 `cluster.toml`
- 支持 connector, collector, warmup, bots 配置
- 配置验证和变更检测

**supervisor/src/manager.rs** - 进程管理
- `BotManager` 管理多个Bot进程
- 启动/停止/重启单个或全部Bot
- SIGTERM优雅关闭，30秒超时后SIGKILL
- 崩溃自动重启，可配置退避时间和最大重启次数

**supervisor/src/warmup.rs** - Warmup协调
- `WarmupChecker` 检查预热数据就绪状态
- 支持 `.jsonl`（边写边读）和 `.gz` 文件
- 验证数据年龄和时长要求

**supervisor/src/health.rs** - 健康检查
- 系统资源监控 (CPU, 内存, 磁盘)
- 进程存活检查
- Connector/Collector 状态检测

**supervisor/src/ipc.rs** - Unix Socket IPC
- `ControlServer` 监听控制命令
- `ControlClient` 发送控制命令
- JSON 协议通信

**supervisor/src/main.rs** - 主程序
- 信号处理: SIGTERM/SIGINT 优雅关闭, SIGHUP 重载配置
- inotify 文件监视器自动检测配置变更
- 启动时自动启动所有 enabled 的 Bot

**supervisor/src/hftctl.rs** - 命令行工具
- `hftctl status` - 查看集群状态
- `hftctl start/stop/restart <bot_id>` - 控制单个Bot
- `hftctl restart-all` - 重启所有Bot
- `hftctl reload` - 重载配置
- `hftctl validate <config>` - 验证配置文件

### 使用方法

```bash
# 构建
cargo build --release -p hft-supervisor

# 验证配置
hftctl validate /etc/hft/cluster.toml

# 启动 supervisor
hft-supervisor --config /etc/hft/cluster.toml --bin-dir /opt/hft/bin

# 查看状态
hftctl --socket /run/hft/supervisor.sock status

# 控制 Bot
hftctl start obi_mm_btcusdt
hftctl stop obi_mm_btcusdt
hftctl restart obi_mm_btcusdt

# 重载配置
kill -HUP $(pgrep hft-supervisor)
```

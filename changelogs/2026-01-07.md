## 启动流程

```bash
# 1. 启动 Supervisor
./target/release/hft-supervisor -c cluster.toml --bin-dir ./target/release

# 2. 启动 Server
./target/release/hft-server --config cluster.toml --socket /tmp/hft-supervisor.sock --database-url ./hft-server.db --port 3001

# 3. 启动 Connector
./target/release/connector bf binancefutures binancefutures.toml

# 4. 通过 API 控制
curl -X POST http://127.0.0.1:3001/api/auth/login -d '{"username":"admin","password":"admin"}'
curl http://127.0.0.1:3001/api/bots -H "Authorization: Bearer $TOKEN"
curl -X POST http://127.0.0.1:3001/api/bots/obi_mm_btcusdt/start -H "Authorization: Bearer $TOKEN"
```

**修复**:

**supervisor/src/manager.rs**
- 新增 `BotInfo` 结构体用于 IPC 状态报告
- 新增 `get_all_bot_info()` 方法 - 返回所有 bot 完整信息
- 新增 `get_bot_info(bot_id)` 方法 - 返回单个 bot 完整信息
- 包含: id, symbol, state, pid, uptime_secs, restart_count

**supervisor/src/ipc.rs**
- 更新 `Status` 命令使用 `manager.get_all_bot_info()`
- 更新 `BotStatus` 命令使用 `manager.get_bot_info()`

## Order Recorder 集成

### 概述

将 Order Recorder 服务完全集成到 HFT 管理系统，支持通过 Dashboard 和 API 控制。

### 功能

Order Recorder 用于记录交易事件到 ClickHouse 数据库：
- 订单事件 (orders)
- 成交事件 (fills)
- 持仓快照 (positions)
- 策略状态 (strategy_status)

### 配置

**cluster_testnet.toml**
```toml
[order_recorder]
enabled = true
auto_start = false
ipc_service = "hft_recording"
clickhouse_url = "http://localhost:8123"
database = "hft"
batch_size = 100
flush_interval_secs = 5
```

### API 端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/infra/order_recorder` | GET | 获取状态 |
| `/api/infra/order_recorder/start` | POST | 启动服务 |
| `/api/infra/order_recorder/stop` | POST | 停止服务 |
| `/api/infra/order_recorder/restart` | POST | 重启服务 |

### 二进制文件

创建符号链接:
```bash
sudo ln -sf /path/to/target/release/order-recorder /opt/hft/bin/order-recorder
```

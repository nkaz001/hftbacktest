# 改动总结 - 2026-01-07

## HFT Server - Web API 服务 (Phase 2 完成)

### 新增 `server` crate

实现了 HFT 多Bot管理系统的 Web API 服务，提供 REST API 和 WebSocket 实时事件推送。

### 新增文件

**server/Cargo.toml** - crate 配置
- 依赖: axum, sqlx, jsonwebtoken, argon2, tower-http, chrono, tokio

**server/src/main.rs** - 服务入口
- Axum 路由配置
- CORS 中间件
- 静态文件服务

**server/src/state.rs** - 应用状态
- 集群配置管理
- 广播通道

**server/src/supervisor.rs** - Supervisor IPC 客户端
- Unix Socket 通信
- 状态查询、Bot控制命令

**server/src/api/** - REST API 模块
- `bots.rs` - Bot 管理 (列表、详情、启动、停止、重启)
- `config.rs` - 配置管理 (集群配置、策略配置 CRUD)
- `status.rs` - 集群状态总览
- `logs.rs` - 审计日志查询
- `data.rs` - 数据文件管理

**server/src/auth/mod.rs** - 认证模块
- JWT Token 生成和验证
- Argon2 密码哈希
- 登录/登出/会话管理

**server/src/db/mod.rs** - 数据库模块
- SQLite 连接池
- 用户、会话、审计日志、Bot状态历史表
- 自动创建数据库和默认管理员用户

**server/src/ws/mod.rs** - WebSocket 模块
- 实时状态推送
- JWT 认证
- 广播机制

**server/migrations/001_init.sql** - 数据库迁移

**server/README.md** - 完整使用文档
- 架构概览
- 从零到一启动流程
- API 参考
- WebSocket 事件格式
- 配置说明

### 测试文件

**server/tests/api_tests.rs** - API 集成测试 (14个)
**server/tests/db_tests.rs** - 数据库测试 (7个)
**server/tests/common/mod.rs** - 测试工具

## 启动流程

```bash
# 1. 启动 Supervisor
./target/release/hft-supervisor -c cluster.toml --bin-dir ./target/release

# 2. 启动 Server
./target/release/hft-server --config cluster.toml --socket /tmp/hft-supervisor.sock --database-url ./hft-server.db --port 3001

# 3. 启动 Connector
./target/release/connector bf binancefutures binancefutures.toml

# 4. 通过 API 控制
curl -X POST http://127.0.0.1:3001/api/auth/login -d '{"username":"admin","password":"admin"}'
curl http://127.0.0.1:3001/api/bots -H "Authorization: Bearer $TOKEN"
curl -X POST http://127.0.0.1:3001/api/bots/obi_mm_btcusdt/start -H "Authorization: Bearer $TOKEN"
```

## Phase 3: React Dashboard (已完成)

### 新增 `server/dashboard` 前端项目

基于 React + TypeScript + Vite 实现的 Web 管理界面。

### 技术栈

- **React 18** + TypeScript
- **Vite 7** - 构建工具
- **TailwindCSS 4** - 样式框架
- **@tanstack/react-query** - 数据获取
- **Zustand** - 状态管理
- **React Router 6** - 路由
- **Lucide React** - 图标

### 项目结构

```
server/dashboard/
├── src/
│   ├── api/client.ts           # API 客户端
│   ├── types/index.ts          # TypeScript 类型
│   ├── stores/useStore.ts      # Zustand 状态
│   ├── hooks/
│   │   ├── useWebSocket.ts     # WebSocket 实时连接
│   │   ├── useBots.ts          # Bot 数据 hooks
│   │   └── useStatus.ts        # 状态 hooks
│   ├── components/
│   │   ├── ui/                 # 基础 UI 组件
│   │   │   ├── Button.tsx
│   │   │   ├── Card.tsx
│   │   │   └── Badge.tsx
│   │   └── layout/
│   │       ├── Sidebar.tsx     # 侧边栏导航
│   │       ├── Header.tsx      # 顶部栏
│   │       └── Layout.tsx      # 布局容器
│   └── pages/
│       ├── Login.tsx           # 登录页
│       ├── Dashboard.tsx       # 首页总览
│       ├── Bots.tsx            # Bot 管理
│       ├── Config.tsx          # 配置查看
│       ├── Data.tsx            # 数据管理
```

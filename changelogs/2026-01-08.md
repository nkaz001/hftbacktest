# 改动总结 - 2026-01-08

## Docker Compose 一站式部署 (Phase 4)

### 概述

实现了 HFT 交易系统的 Docker 一键部署方案，包含所有组件的容器化和多 Bot/多币种支持。

### 新增 `deploy/docker/` 目录

```
deploy/docker/
├── Dockerfile              # 多阶段构建 (Node.js + Rust + Runtime)
├── docker-compose.yml      # 服务编排 (ClickHouse + HFT)
├── entrypoint.sh          # 容器启动脚本 (权限处理、配置注入)
├── .env.example           # 环境变量模板
├── .dockerignore          # 构建排除文件
├── README.md              # 完整部署文档
├── config/
│   ├── cluster.toml       # 集群配置 (3 Bot 示例)
│   ├── binancefutures.toml # 交易所连接配置
│   └── strategies/
│       ├── obi_mm.toml    # 默认策略配置
│       ├── obi_mm_btc.toml # BTC/USDT 策略
│       ├── obi_mm_eth.toml # ETH/USDT 策略
│       ├── obi_mm_sol.toml # SOL/USDT 策略
│       └── template.toml   # 模板策略配置
└── scripts/
    └── init-clickhouse.sql # ClickHouse 数据库初始化
```

### Dockerfile 设计

三阶段构建，最小化运行时镜像：

1. **Stage 1: Dashboard Builder (Node.js)**
   - 构建 React Dashboard 前端
   - 产出: `dist/` 静态文件

2. **Stage 2: Rust Builder**
   - 构建所有 Rust 二进制
   - 包含: connector, collector, order-recorder, hft-supervisor, hft-server, obi_mm_live, template_strategy

3. **Stage 3: Runtime (debian:trixie-slim)**
   - 最小运行时环境 (~200MB)
   - 非 root 用户运行 (hft)
   - gosu 权限降级

### Docker Compose 服务

| 服务 | 镜像 | 端口 | 说明 |
|------|------|------|------|
| clickhouse | clickhouse/clickhouse-server:24.8 | 18123, 19000 | 订单记录数据库 |
| hft | docker-hft (本地构建) | 13000 | HFT 交易系统 |

### 端口映射

避免与本地服务冲突：
- 13000 → 3000 (Web Dashboard)
- 18123 → 8123 (ClickHouse HTTP)
- 19000 → 9000 (ClickHouse Native)

### entrypoint.sh 功能

1. **配置文件处理** (以 root 运行)
   - 环境变量替换 (API keys)
   - 策略配置复制到 `/tmp/hft-config/`
   - 路径更新

2. **权限处理**
   - 使用 `gosu` 降级到 hft 用户
   - 确保数据目录权限正确

3. **服务启动顺序**
   - 等待 ClickHouse 就绪
   - 启动 hft-server (后台)
   - 启动 hft-supervisor (前台)

### Server 静态文件服务

**server/src/main.rs**
- 添加 `tower_http::services::{ServeDir, ServeFile}`
- 配置 fallback 服务指向 `/var/lib/hft/dashboard`
- SPA 路由支持 (404 fallback 到 index.html)

### 数据库自动初始化

**entrypoint.sh**
- 添加 `--database-url "sqlite:/var/lib/hft/hft-server.db?mode=rwc"`
- 自动创建 SQLite 数据库
- 自动创建默认用户 (admin/admin)

### 多 Bot / 多币种支持

**config/cluster.toml** 示例配置 3 个 Bot：

```toml
[collector]
symbols = ["btcusdt", "ethusdt", "solusdt"]

[[bots]]
id = "obi_mm_btcusdt"
symbol = "btcusdt"
config_file = "/etc/hft/strategies/obi_mm_btc.toml"

[[bots]]
id = "obi_mm_ethusdt"
symbol = "ethusdt"
config_file = "/etc/hft/strategies/obi_mm_eth.toml"

[[bots]]
id = "obi_mm_solusdt"
symbol = "solusdt"
config_file = "/etc/hft/strategies/obi_mm_sol.toml"
```

## Quick Start

```bash
cd deploy/docker

# 1. 配置 API Keys
cp .env.example .env
# 编辑 .env 添加 BINANCE_API_KEY 和 BINANCE_SECRET

# 2. 构建和启动
docker compose build    # 首次构建 30-45 分钟
docker compose up -d

# 3. 访问
# Dashboard: http://localhost:13000
# 登录: admin / admin
```

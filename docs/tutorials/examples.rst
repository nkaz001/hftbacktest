Examples
========

You can find more examples `here <https://github.com/nkaz001/hftbacktest/tree/master/examples>`_

* `CryptoHFTData Workflow <https://github.com/nkaz001/hftbacktest/blob/master/examples/CryptoHFTData%20Workflow.ipynb>`_: Download CryptoHFTData orderbook and trades data, convert it into HftBacktest's normalized format, derive an end-of-day snapshot, and run a simple backtest.

* `CryptoHFTData script <https://github.com/nkaz001/hftbacktest/blob/master/examples/cryptohftdata.py>`_: Download an inclusive date range and convert it to a compressed HftBacktest event file from the command line.
